# TaskFlow — Personal To-Do List

TaskFlow is a simple, responsive To-Do List web application built using HTML, CSS, and JavaScript. It features a clean blue-and-white dashboard inspired by modern productivity applications.

## Features

- Add new tasks with different priority levels.
- Mark tasks as completed or pending.
- Edit and delete tasks.
- Search tasks by name.
- Filter tasks by status: All, Pending, and Completed.
- View total tasks, completed tasks, pending tasks, and progress statistics.
- Toggle between light and dark themes.
- Smooth animations and interactive hover effects.
- Responsive design for desktop and mobile screens.

## Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling, responsive layout, and animations
- **JavaScript** — Task management and interactive functionality

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Fakruddin-Coder/TaskFlow-Todo-List
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.

No additional dependencies or installation are required.
